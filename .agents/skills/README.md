# Agent Workflow Skills

Canonical home for project-specific agent workflows. Each skill is a directory containing one `SKILL.md` with matching `name` and a useful `description` in YAML frontmatter.

| Skill | Purpose |
|---|---|
| [code-audit](./code-audit/SKILL.md) | Review correctness, security, architecture boundaries, and tests. |
| [repo-snapshot](./repo-snapshot/SKILL.md) | Create a compact repository handoff snapshot. |
| [service-refactor](./service-refactor/SKILL.md) | Refactor one service/client while preserving repository and contract boundaries. |
| [workspace-organization](./workspace-organization/SKILL.md) | Keep documentation, skills, and configuration in canonical locations. |
